Three data types. One content address. Dropping this week.

---

We have been building something for the past few months that sits at the intersection of IPFS, AI model registries, and structured data. The problem we kept running into: every production application that does something real needs blobs, model weights, and queryable records. Today those are three separate providers, three separate auth systems, and no shared CID story.

That is about to change. We are publishing a specification this week that defines a single canonical envelope and three data planes — all content-addressed, all verifiable, all under one authentication surface. The spec is CC-BY 4.0. The reference implementation is Apache-2.0. Any provider can implement it.

Follow NDN Analytics here for the full announcement. The spec, the live implementation URL, and the discovery endpoint drop together.
